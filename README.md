# LN Downloader Bot — просунутий Telegram-бот для завантаження ранобе за посиланням

Сфокусований, легкий і швидкий асинхронний бот (`aiogram 3.x` + `httpx` + `BeautifulSoup4`), без зайвого функціоналу — лише завантаження та збірка книг:

* **Автовизначення типу посилання:**
  * **Веб-книга / сторінка зі змістом** (Royal Road, відкриті вебновели, блоги, HTML-сторінки з розділами) — знаходить список розділів, обкладинку, автора.
  * **Відкритий каталог файлів** — витягує всі `.epub`, `.pdf`, `.txt`, `.fb2`, `.zip` із директорії з можливістю скачати 1 файл або всі пакетом.
  * **Пряме посилання на файл** — миттєво завантажує й відправляє в чат.
* **Вибір формату й діапазону розділів:** інтерактивні кнопки в Telegram (`Усі розділи`, `Останні 20`, `Свій діапазон` типу `1-50` або `10,15,20-35`) у форматі **`EPUB 3`** (зі змістом `nav.xhtml`/`toc.ncx` та обкладинкою) або **`TXT`**.
* **SQLite-кеш розділів:** повторне завантаження або оновлення тайтлу не перекачує старі розділи, а бере їх із кешу й докачує лише нові.
* **Паралельне завантаження з rate-limit, ретраями та `/cancel`:** живий прогрес-бар у повідомленні.
* **Опційне вивантаження на Google Drive:** якщо файл перевищує 48 МБ (ліміт Telegram Bot API), бот автоматично завантажить його в `Переклади ранобе/<Title>/originals/` і надішле посилання.

> **Важливо:** бот працює через стандартний HTTP-клієнт із повагою до `robots.txt` і не містить обходу Cloudflare чи антибот-захисту.

## Запуск
```bash
cp .env.example .env
# Впиши BOT_TOKEN (від @BotFather) та ALLOWED_USER_IDS (твій Telegram ID)
pip install -r requirements.txt
python3 bot.py
```
Або через Docker:
```bash
docker compose up -d --build
```
